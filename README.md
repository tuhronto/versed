# Versed

Synced lyrics in your Discord status. Versed shows the line you're hearing on your profile while you listen in Spotify, Apple Music, TIDAL or your browser.

**[Download for Windows](https://github.com/tuhronto/versed/releases/latest/download/Versed-Setup.exe)** (Windows 10 and 11) or see the [website](https://getversed.vercel.app).

![Versed](https://getversed.vercel.app/shots/now.webp)

- Lyrics from LRCLIB, paced to Discord's update limit
- Romanization for Japanese and Korean lyrics
- Lyrics overlay for games and video
- Lyric cards, custom status layouts, media controls
- Updates itself

Installed copies update automatically. Windows SmartScreen may warn about the installer because it isn't code-signed yet: choose More info, then Run anyway.

Found a problem? [Open an issue](https://github.com/tuhronto/versed/issues).

This repository only hosts releases and the website.
